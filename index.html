💻 Akademi Coding

Belajar membuat website dari dasar. Coding adalah kegiatan menulis instruksi agar komputer menjalankan tugas tertentu.

1. HTML — Struktur halaman

HTML (HyperText Markup Language) menyusun isi halaman seperti judul, paragraf, gambar, dan tombol. HTML memakai elemen yang biasanya memiliki tag pembuka dan penutup.

<h1>Halo, dunia!</h1>
<p>Ini halaman pertamaku.</p>

Penjelasan: h1 membuat judul utama, sedangkan p membuat paragraf.

2. CSS — Tampilan halaman

CSS (Cascading Style Sheets) mengatur warna, ukuran teks, jarak, dan tata letak agar halaman mudah dibaca.

h1 {
  color: deepskyblue;
  font-size: 28px;
}

Penjelasan: aturan tersebut mengubah warna judul menjadi biru muda dan ukurannya menjadi 28 piksel.

3. JavaScript — Interaksi

JavaScript membuat halaman merespons tindakan, misalnya tombol yang menampilkan pesan atau menghitung nilai.

function sapa() {
  alert('Halo, selamat belajar!');
}

Penjelasan: function membuat fungsi bernama sapa; saat dipanggil, fungsi menampilkan pesan.

4. Urutan belajar yang disarankan

HTMLCSSJavaScriptGitProyek mini

Mulai dari struktur HTML, percantik dengan CSS, tambahkan interaksi JavaScript, lalu simpan perubahan menggunakan Git. Latihan proyek pertama: halaman profil sederhana.

🖥️ Akademi Manajemen Informatika

Manajemen Informatika mempelajari cara menggunakan teknologi informasi untuk mengelola data, mendukung pekerjaan, dan membantu organisasi mengambil keputusan.

Apa yang dipelajari?

1. Dasar komputer: mengenal perangkat keras, perangkat lunak, sistem operasi, dan cara kerja komputer.

2. Pemrograman: memahami logika, algoritma, dan membuat program sederhana.

3. Basis data: menyimpan, mengatur, mencari, dan menjaga konsistensi data menggunakan konsep tabel dan SQL.

4. Analisis dan perancangan sistem: memahami kebutuhan pengguna lalu merancang alur aplikasi yang sesuai.

5. Jaringan komputer: mempelajari koneksi perangkat, internet, server, dan dasar keamanan jaringan.

6. Sistem informasi: menggabungkan manusia, proses kerja, data, dan teknologi agar informasi berguna bagi organisasi.

Contoh penerapan

Sebuah toko membutuhkan aplikasi stok barang. Mahasiswa Manajemen Informatika dapat membantu menganalisis kebutuhan toko, merancang database barang, membuat aplikasi pencatatan, lalu menyusun laporan stok.

Kemampuan yang dibangun

LogikaAnalisisDatabasePemrogramanKomunikasiPemecahan masalah

Bidang pekerjaan yang berkaitan antara lain pengembang aplikasi junior, administrator basis data junior, analis sistem junior, staf IT, dan pengelola sistem informasi. Pilihan karier bergantung pada keterampilan dan pengalaman yang dikembangkan.
